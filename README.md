# Live Character Counter

A simple and interactive Live Character Counter website built using HTML, CSS, and JavaScript. It helps users count characters in real time while typing in a text area.

## 🚀 Features

- Live character counting
- Real-time character updates
- Simple and user-friendly interface
- Responsive design
- Clean and minimal UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📸 How It Works

1. Enter your text in the text area.
2. The character count updates automatically.
3. See the total number of characters instantly.

## 🎯 Purpose

This project was created to practice HTML, CSS, and JavaScript concepts, especially DOM manipulation and event handling.
